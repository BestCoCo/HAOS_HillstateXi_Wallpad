# 현대HT 월패드 Home Assistant 연동 (EW11 RS485)

힐스테이트 자이 아산센텀(현대에이치티 **HDHN-3500-TH** 월패드)의 RS485 신호를 **EW11(RS485→Wi-Fi) 3대**로 받아 Home Assistant에서 읽고 제어하는 커스텀 통합입니다. 클라우드 없이 집 안 네트워크만 씁니다.

> 비공식 프로젝트입니다. 현대에이치티·현대건설과 관계없으며, 사용에 따른 책임은 사용자에게 있습니다.

## 지원 기능
| 기기 | 읽기 | 제어 |
|---|---|---|
| 조명 (방·회로별) | ✅ | 켜기/끄기, 방 전체 끄기, 집 전체 소등 |
| 난방 (방별) | 모드·현재·설정 온도 | 켜기/끄기, 설정 온도 |
| 환기 | 전원·세기 | 켜기/끄기, 약·중·강 (켜고 끄는 간격 20초 이상) |
| 대기전력 콘센트 | 켜짐·자동차단·**전력(W)** | 차단/해제, 자동/수동 |
| 엘리베이터 | 호출 중, 도착, 층(월패드 화면 볼 때만) | ❌ |
| 일괄 스위치 | 일괄소등 설정 여부 | ❌ (조명은 "집 전체 소등" 버튼으로 대신) |

이벤트 `ht_wallpad_event` (`type`): `elevator_called`, `elevator_arrived`, `batch_off_set`, `batch_off_released`, `hall_button_pressed`

## 준비물
월패드 뒤 RS485 단자에 EW11을 **기존 선과 병렬로** 연결합니다 (A→A, B→B).

| EW11 | 월패드 단자 | 내용 |
|---|---|---|
| 1 | RS-485 1 (1A/1B) | 일괄 스위치 · 엘리베이터 |
| 2 | RS-485 1 (2A/2B) | 조명 · 대기전력 콘센트 |
| 3 | RS-485 2 (3A/3B) | 난방 · 환기 · 가스 |

EW11 설정: 9600 / 8 / 1 / None, Flow Control 없음, **Cli Disable**, Protocol None, Communication `TCP Server` 포트 `8899`.

## 설치
- **HACS**: 사용자 지정 저장소에 이 저장소 주소를 `통합구성요소`로 추가 → 설치 → HA 재시작
- **수동**: `custom_components/ht_wallpad` 폴더를 HA의 `/config/custom_components/`에 복사 → 재시작

## 설정 (`configuration.yaml`)
```yaml
ht_wallpad:
  elevator_host: 192.168.0.26   # EW11 1
  light_host: 192.168.0.27      # EW11 2
  heat_host: 192.168.0.28       # EW11 3
  # port: 8899
  protected_outlets: ["51", "52"]   # 차단 스위치를 만들지 않을 콘센트 (예: 서버 전원)
  fan_area: 거실                    # 환기 기기 영역
  main_area: 현관                   # 엘리베이터·일괄소등 기기 영역
  rooms:                            # 생략하면 거실/침실1~3/알파룸/주방 기본값
    - id: living
      name: 거실
      light_group: "10"             # 16진수 문자열로 (따옴표 필수)
      lights: ["1", "2", "복도"]
      heat: "11"
      area: 거실                    # HA 영역 이름 (생략하면 name)
    - id: kitchen
      name: 주방
      light_group: "60"
      lights: ["1", "2", "3"]
```

방마다 `월패드 <방>` 기기가 생기고, 처음 생성될 때 해당 영역(area)에 자동으로 들어갑니다.

## 프로토콜 요약
`F7 | 길이 | 01 | 기기 | 명령 | 종류 | 번호 | 데이터… | XOR | EE` — 명령 01 상태요청 / 02 제어 / 04 응답.
기기: 18 난방, 19 조명, 1B 가스, 1F 콘센트, 2A 일괄, 2B 환기, 34 엘리베이터, 44 시간, 48 복도 버튼.
제어 예: 조명 `19 02 40 [회로|그룹] [01 켜기|02 끄기] 00`, 난방 전원 `18 02 46 [방] [01|04] 00`, 설정 온도 `18 02 45 [방] [온도] 00`, 환기 `2B 02 40 11 [01|02] 00` / 세기 `2B 02 42 11 [01|03|07] 00`, 콘센트 `1F 02 40 [번호] [01|02] 00` / 자동 `1F 02 57 [번호] [01|02] 00`.

명령은 월패드가 그 기기를 폴링해 응답이 지나간 **직후**에 보내야 잘 받아들여집니다. 이 통합은 응답 확인 후 최대 8회 재시도합니다.
